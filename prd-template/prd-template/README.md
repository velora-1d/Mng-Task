# PRD Template

Struktur PRD global, fleksibel untuk semua jenis aplikasi (SaaS, dashboard, mobile+dashboard, ERP, dll). Semua 15 section wajib diisi.

## Isi
- `PRD-MASTER-TEMPLATE.md` — template gabungan siap pakai, tinggal isi tiap section
- `sections/` — 15 file section terpisah (kalau mau isi satu-satu / assign per bagian)

## Cara pakai
1. Copy `PRD-MASTER-TEMPLATE.md` jadi `PRD-[nama-project].md`
2. Isi tiap section sesuai brief client
3. Section yang tidak relevan tetap dicantumkan, isi dengan "N/A" + alasan singkat (bukan dihapus, biar histori keputusan scope tetap ada)
