# 2. Problem Statement & Goals

## Problem Statement

- Masalah : banyak catatan tugas bercecran,susah tracking tugas,sulit memuat laporan harian dan bulanan
- Dampak masalah tersebut kalau tidak diselesaikan : akan mengganggu pekerjaan dan dapat mengurangi produktivitas

## Goals

- Tujuan utama aplikasi : Membantu user untuk mencatat,tracking,dan membuat laporan tugas
- Success metric : User dapat mencatat,tracking,dan membuat laporan tugas dengan mudah dan cepat,serta dapat meningkatkan produktivitas
