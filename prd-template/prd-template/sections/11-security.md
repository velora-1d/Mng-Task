# 11. Security Requirements

- Enkripsi data sensitif (sudah terenkripsi di Neon DB) : Password Wajib di Hash dan salt
- Rate limiting / proteksi API : Rate Limiting Wajib Diterapkan pada tombol 1 kali dan pakai animasi loading
- Backup & recovery policy : Backup otomatis setiap 7 hari sekali
- Compliance yang perlu diikuti (jika ada) : Tidak ada
