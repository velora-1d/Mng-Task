# 9. Business Process

- Proses bisnis yang diotomasi oleh sistem :
  1. Owner dapat menambahkan user
  2. Owner dapat mengedit user
  3. Owner dapat menghapus user
  4. Owner dapat menambahkan task
  5. Owner dapat mengedit task
  6. Owner dapat menghapus task
  7. Owner dapat menambahkan report
  8. Owner dapat mengedit report
  9. Owner dapat menghapus report
  10. Owner dapat menambahkan reminder
  11. Owner dapat mengedit reminder
  12. Owner dapat menghapus reminder
  13. User dapat menambahkan task
  14. User dapat mengedit task
  15. User dapat menghapus task
  16. User dapat menambahkan report
  17. User dapat mengedit report
  18. User dapat menghapus report
  19. User dapat menambahkan reminder
  20. User dapat mengedit reminder
  21. User dapat menghapus reminder
