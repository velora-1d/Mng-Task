# 8. Functional Requirements

## Authentication

- Ada login/tidak
- Metode login (email/password, OTP, SSO, dll) : email dan password
- Role & permission mapping per menu : role ada 2 yaitu owner,user

## Validasi

- Validasi input per form penting :
  - Nama user tidak boleh kosong
  - Email tidak boleh kosong
  - Password tidak boleh kosong
  - Role tidak boleh kosong
  - Nama task tidak boleh kosong
  - Deskripsi task tidak boleh kosong
  - Deadline task tidak boleh kosong
  - Status task tidak boleh kosong
  - Nama report tidak boleh kosong
  - Deskripsi report tidak boleh kosong
  - Deadline report tidak boleh kosong
  - Status report tidak boleh kosong
  - Nama reminder tidak boleh kosong
  - Deskripsi reminder tidak boleh kosong
  - Deadline reminder tidak boleh kosong
  - Status reminder tidak boleh kosong
